## TOEFL 风格练习

### Listening 练习

听力中常考“教授态度/组织结构”。用以下词组复述一段 45 秒讲座结构：

- professor introduces the topic
- gives two causes
- provides an example
- explains the consequence
- concludes with a solution

要求：必须使用 5 个词：indicate, demonstrate, figure, section, detail。

### Speaking 练习

题目：Some students prefer to deal with pressure on their own, while others prefer to ask friends or advisors for help. Which do you prefer?

结构：

1. I prefer ...
2. First, ...
3. Second, ...
4. For example, ...
5. That's why ...

必须尝试使用：

- deal with pressure
- form a positive cycle
- play a vital role in
- make progress

### Reading 练习

从 “The Origins of Cetaceans” 词汇中任选 12 个，按下面格式造题：

- 题干：According to the passage, what does `vestigial` suggest about the body part?

- 干扰项提醒：不要把 vestigial 理解成 “important / fully functional”。

## 易混点

| 易混点 | 区分 |
|---|---|
| affect / effect | affect 多作动词“影响”；effect 多作名词“影响、效果”。 |
| personal / personnel | personal = 个人的；personnel = 人员。笔记里是 personal。 |
| imply / identify | imply = 暗示；identify = 识别、认出。 |
| valuable / invaluable | valuable = 有价值的；invaluable = 极其宝贵的，不是“没价值”。 |
| desert / dessert | desert = 沙漠；dessert = 甜点。 |
| sensible / sensitive / susceptible | sensible = 明智的；sensitive = 敏感的；susceptible = 易受影响的。 |
| admission / permission | admission = 准入/入场；permission = 许可。 |
| current / constant | current = 当前的；constant = 持续的。 |
